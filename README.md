**SECURITY ACCESS AND IDENTITY MANAGEMENT SYSTEM**

=> **Key features:**
1. Access Control Processing:Automated card swipe evaluation checking student access levels, room requirements, and restricted operating hours.

2. Automated Security Triggers:
  - Auto-blocks student accounts after 3 consecutive access failures within 30 minutes.
  - Detects rapid multi-room movements (reconnaissance pattern detection).
  - Flags lost card usage and generates real-time security alerts.
    
3. Admin Dashboard: Overview metrics, active security alerts, access logs, and student status management.
4. Card Swipe Simulator: Interactive interface to test different access scenarios, room restrictions, and card statuses.
